# PL/SQL Practice - Week 1

This folder contains the PL/SQL programs that I practiced during Week 1. These programs helped me understand the basics of Oracle PL/SQL, including variables, loops, cursors, exceptions, procedures, functions, triggers, and packages.

## Files Included

| File Name                   | Description                                                  |
| --------------------------- | ------------------------------------------------------------ |
| 01_basics.sql               | Basic PL/SQL programs using variables, conditions, and loops |
| 02_cursors.sql              | Examples of implicit and explicit cursors                    |
| 03_exceptions.sql           | Exception handling examples                                  |
| 04_procedures_functions.sql | Simple procedures and functions                              |
| 05_triggers.sql             | Basic trigger examples for insert, update, and delete        |
| 06_packages.sql             | Package specification and package body examples              |

## Topics Covered

* Variables and Data Types
* IF-ELSE Statements
* Loops
* Cursors
* Exception Handling
* Stored Procedures
* Functions
* Triggers
* Packages

## Basic PL/SQL Structure

```sql
DECLARE
   -- variables
BEGIN
   -- statements
EXCEPTION
   -- error handling
END;
/
```

## Learning Outcome

By completing these programs, I learned how to write PL/SQL blocks, handle database operations, create reusable procedures and functions, and work with triggers and packages in Oracle Database.
