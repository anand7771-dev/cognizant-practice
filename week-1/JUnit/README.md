# JUnit 5 Practice - Week 1

This folder contains basic JUnit 5 programs that I practiced to understand unit testing in Java. The examples cover simple test cases, assertions, and commonly used JUnit annotations.

## Files Included

| File Name               | Purpose                                 |
| ----------------------- | --------------------------------------- |
| Calculator.java         | Java class used for testing             |
| CalculatorTest.java     | Basic test cases for calculator methods |
| ParameterizedTests.java | Examples using different input values   |
| LifecycleTest.java      | Demonstrates test lifecycle methods     |

## Topics Covered

* Introduction to JUnit 5
* Writing test cases
* Assertions
* Parameterized tests
* Test lifecycle methods
* Running and verifying tests

## Common Annotations Used

* @Test
* @BeforeEach
* @AfterEach
* @BeforeAll
* @AfterAll
* @ParameterizedTest
* @ValueSource
* @CsvSource

## Common Assertions

* assertEquals()
* assertTrue()
* assertFalse()
* assertNotNull()
* assertNull()
* assertThrows()

## Objective

The goal of this week's practice is to learn how unit testing works in Java and how JUnit 5 helps verify that a program behaves as expected.
