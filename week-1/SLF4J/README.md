# SLF4J Practice - Week 1

This folder contains basic programs to learn logging in Java using SLF4J and Logback. Logging helps developers track application activities, errors, and important messages while the program is running.

## Files Included

| File Name         | Description                    |
| ----------------- | ------------------------------ |
| SLF4JBasics.java  | Basic logging examples         |
| OrderService.java | Simple service logging example |
| logback.xml       | Logback configuration file     |

## Topics Covered

* Introduction to SLF4J
* Logger Creation
* Log Levels
* Console Logging
* File Logging
* Logback Configuration

## Log Levels

* TRACE
* DEBUG
* INFO
* WARN
* ERROR

## Purpose

The purpose of this practice is to understand how logging works in Java applications and how SLF4J can be used with Logback to generate log messages.

## Tools Used

* Java
* SLF4J
* Logback
* Maven
