# Design Patterns - Week 1

This folder contains basic Java programs for commonly used Design Patterns. These patterns help developers write code that is easier to manage, reuse, and understand.

## Types of Design Patterns

### Creational Patterns

These patterns are related to object creation.

* Singleton Pattern
* Factory Pattern
* Builder Pattern

### Structural Patterns

These patterns focus on how classes and objects are connected.

* Adapter Pattern
* Decorator Pattern
* Proxy Pattern

### Behavioral Patterns

These patterns define how objects communicate with each other.

* Observer Pattern
* Strategy Pattern
* Command Pattern

### Architectural Patterns

These patterns define the overall structure of the application.

* MVC Pattern
* Dependency Injection
