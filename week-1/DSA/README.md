# DSA Practice - Week 1

This folder contains the programs that I practiced during Week 1 while learning Data Structures and Algorithms in Java.

## Programs Included

| File Name           | Description                              |
| ------------------- | ---------------------------------------- |
| LinearSearch.java   | Search an element one by one in an array |
| BinarySearch.java   | Search an element in a sorted array      |
| BubbleSort.java     | Sort elements using Bubble Sort          |
| MergeSort.java      | Sort elements using Merge Sort           |
| QuickSort.java      | Sort elements using Quick Sort           |
| LinkedList.java     | Basic implementation of Linked List      |
| Stack.java          | Stack operations using Java              |
| Queue.java          | Queue operations using Java              |

## Concepts Learned

* Searching Algorithms (Linear and Binary)
* Sorting Algorithms (Bubble, Merge, Quick)
* Time Complexity Basics
* Linked List Operations
* Stack Implementation
* Queue Implementation

## Time Complexity Overview

| Complexity | Meaning                      |
| ---------- | ---------------------------- |
| O(1)       | Constant Time                |
| O(log n)   | Logarithmic Time             |
| O(n)       | Linear Time                  |
| O(n log n) | Efficient Sorting Complexity |
| O(n²)      | Nested Loop Complexity       |

## Objective

Build a strong foundation in DSA by understanding basic algorithms and data structures through Java programs.
