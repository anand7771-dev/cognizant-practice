## 📝 How to Run

### Java Files (Week 1)
```bash
# Compile
javac FileName.java

# Run
java FileName
```

### Spring Boot Projects (Week 2 onwards)
```bash
# Run with Maven
mvn spring-boot:run

# Or build jar and run
mvn clean package
java -jar target/project-name.jar
```
