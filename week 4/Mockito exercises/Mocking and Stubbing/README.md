# Mockito Hands-On Exercises

## Exercise 1 - Mocking and Stubbing

This project demonstrates how Mockito can be used to mock an external dependency and return predefined values during unit testing.

### Concepts Covered

- Mockito
- Mock Objects
- Stubbing
- JUnit 4
- Maven

### Tools Used

- Java
- Maven
- JUnit 4.13.2
- Mockito 5
